# SugarFree

**A virtual pancreas simulator you can play.**

SugarFree is an educational game about blood glucose regulation, prepared for the Fête de la Science.

## Download

**[Download the latest version](../../releases/latest)**

On the release page, under **Assets**, click `SugarFree.exe`.

## Run on Windows

1. Download `SugarFree.exe`.
2. Double-click it. No installation or account is needed.
3. If Windows shows a blue "Windows protected your PC" window, click **More info**, then **Run anyway**.

The first start can take a few seconds.

## Linux

A native Linux build is not available yet. As a fallback, the Windows version may run with Wine:

```
wine SugarFree.exe
```
